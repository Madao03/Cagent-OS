常见问题

为什么有些数字带 ⚠️？
该数字未在本系统的结构化数据工具中找到匹配来源。可能来自 LLM 自身知识或外网搜索结果。请参考上文「怎么读这些标注」。
为什么问港股回答不了？
港股主板仅强制半年度披露（中期报 + 年报），不存在 Q1/Q3 单季报告。对于纯港股（腾讯/汇丰/友邦等），HKEXnews 披露以 PDF 为主，本系统未接入结构化解析。美股+港股双重上市的中概股走 EDGAR 通道，覆盖度好得多。
为什么同一个数有两种口径？
常见于净利润 vs 归母净利润、营业总收入 vs 营业收入。会计准则允许这些差异存在——系统会尽量标注口径（如"归母"），而不是强行合并。
系统显示「数据不可得」是不是坏了？
不是。这是有意为之。某些数据在制度上不存在（如纯港股季度报告），或本系统未覆盖。我们选择诚实告知，不做推算。这是本系统与普通 AI 聊天机器人最大的区别之一。
