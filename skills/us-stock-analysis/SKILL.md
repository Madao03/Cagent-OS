# 个股分析框架（Equity Analysis）

> 对齐三层分析模式（常态/非常态/黑箱），与 macro-analysis / crypto-analysis 同结构。
> ⚠️ **skill 名仍为 `us-stock-analysis`，但实际覆盖多市场**（改名会牵动 prompt 引用，列为 backlog）。

## 何时触发

- 分析个股基本面/估值/前景（任何市场）
- 财报季个股点评 · 行业板块内个股比较
- 个股内推报告（initiating coverage 简化版）
- 涉及宏观判断 → 同时加载 `macro-analysis`
- 涉及 crypto 相关个股（MSTR/矿企）→ 同时加载 `crypto-stock-analysis`

## ★ 步骤 0：市场路由（在取任何数据之前）

**不同市场的一手源完全不同。先判断标的类型，再决定调什么。**

```
识别市场 → 选取数源
├─ 美股本土（AAPL/MU/NVDA）
│    财报 → financial.edgar.facts（年度·审计·XBRL）
│           financial.edgar.release（季度·8-K Item 2.02）
│    行情 → financial.quote.verified
│
├─ 中概股 ADR（XPEV/BABA/JD）★注意是 FPI
│    财报 → financial.edgar.facts（20-F 年报，审计）
│           financial.edgar.release（6-K 业绩新闻稿，未审计）
│    ⚠️ 无 10-Q；季度数据仅存在于 6-K 新闻稿
│    ⚠️ 记账币种可能是 CNY（非 USD 便利折算）
│
├─ A股（600519/688825/300750）
│    财报 → financial.ashare.report
│    ⚠️ 累计口径：季报是累计值，单季需差分（adapter 已处理，注意读 period_type）
│    ⚠️ 准则 CAS，不与 US_GAAP/IFRS 混算
│    ⚠️ 营业总收入 ≠ 营业收入；净利润 ≠ 归母净利润
│    一手源 → 巨潮公告（announcement_url）
│
├─ 港股（0700/9988/1299）★先判断双重上市
│    美股+港股（中概股）→ 走 EDGAR ✅ 数据更好（季度 vs 半年）
│    A股+H股           → 走 A股通道
│    纯港股（腾讯/汇丰/友邦）→ 只能搜索
│      ⚠️ 主板仅强制半年披露，不存在 Q1/Q3 单季报告（制度性缺失）
│      ⚠️ 准则 HKFRS/IFRS；币种 HKD/CNY/USD 混杂
│
└─ 台股/韩股/其他（2330.TW / 005930.KS）
     无结构化源 → 只能搜索 → 必须声明「未经结构化验证」
     ⚠️★ 币种：KRW/JPY/TWD 的「万亿/兆」极易被误读为美元
```

**结构化源全部失败时 → 触发数据不可得声明**（见 §7），不得用搜索结果静默填补。

## ★ 步骤 0.5：估值口径纪律（本 skill 最高优先级）

> **「PE」这个词禁止裸用。每次出现必须带基准。**

| 名称 | 分母 | 用途 | 陷阱 |
|:-----|:-----|:-----|:-----|
| **TTM PE** | 过去 12 个月**实际**盈利 | 已实现事实 | 周期股严重滞后 |
| **Run-rate PE** | 当期（季/半年）盈利 × 年化 | 反映当下盈利能力 | ★周期顶部极度低估 PE |
| **Forward PE** | 卖方**一致预期**未来 12 月 EPS | 市场预期 | 顶部线性外推 |
| **Normalized PE** | 一轮完整周期的正常化盈利 | ★**周期股主锚** | 需周期均值假设 |

**绝对禁止：把当期年化（run-rate）标注为 forward PE。**

真实事故（CXMT 688825，2026-07-27 首日上市）：
```
同一价格（49.5元 / 市值 3.31万亿）三个基准：
  TTM PE       117x   （2025 全年净利仅 ~20 亿）
  Run-rate PE   31x   （H1'26 净利 500-570 亿 × 2 = 1,070 亿）← 分析误标为 "Forward PE"
  卖方 2028E     8.5x  （野村：EPS 5.8 元 × 20x 目标 → 目标价 116 元）
结论完全取决于选哪个，而输出既未说明基准，也未纳入卖方锚。
```

**规则**
```
① 每个 PE/PS/PB 数字必须在同一行或脚注注明基准与期间
② 周期股禁止单点 PE，必须给三档（见 §2.1.1）
③ 若搜到卖方目标价/目标 PE → 必须纳入并说明其基准年（见 §6）
```

## ★ 步骤 0.6：同业对比纪律

**跨公司对比表，每一列必须通过五项检查：**

```
□ 同一 PE 基准 — 且★每一列都必须单独注明基准与期间，不得只注明其中一列
    格式示例：
      CXMT  31x（H1'26 归母净利 × 2 年化）
      MU     6.4x（FY2026 卖方共识 EPS）
      三星    5.9x（Q2'26 OP × 4 年化 × 净利折算）
    ⚠️ 若某列基准无法确认 → 标「基准未确认」，不得与已确认列并列做倍数比较
□ 同一期间          同财年/同季度（注意财年结日：AAPL 9月 / BABA 3月 / 多数 12月）
□ 同一币种          必须换算 + 注明汇率与汇率日
□ 同一会计准则      US_GAAP / CAS / IFRS 同名科目不可直接比
□ 同一业务范围      三星含手机/家电/代工，与纯存储厂不可比
                    → 必须拆分部，或显式标注「含非主业」
```

**⚠️ 量级异常断言（发现币种错误最快的方式）**
```
单季利润 > 该公司 TTM 全年              → 逻辑不可能，必为币种/口径错误
某公司市值 > 其所在市场总市值            → 同上
净利率 > 80% 且非软件/授权业务           → flag
```

真实事故：三星单季净利被记为 `$58.4B`（实际为 **₩58.4 万亿 ≈ $41.7B**），
年化后得净利 $175B，PE 算成 **6.4x**（实际约 **20x**）。
该数字是"CXMT 31x 显著偏贵"这一结论的支点 —— **口径错误直接翻转结论**。
而正确答案就在同次搜索结果中（"美光 20.8 倍，三星 20 倍，海力士 8 倍"），未被采用。

## 步骤 2：常态性分析 — 估值与质量

### 2.1 估值历史分位

```
- TTM PE vs 自身 5 年区间：____分位
- Forward PE vs TTM PE：折溢价____%（Forward < TTM → 隐含盈利增长）
- PEG < 1 可能低估 / > 2 增长已定价
- EV/EBITDA vs 行业：____
- PB：轻资产（科技）> 3 正常；重资产（制造/银行/IDM）< 2 正常
```

### ★ 2.1.1 周期股估值陷阱（两个方向都要防）

适用：半导体制造/存储/面板/化工/航运/钢铁/煤炭/海运。

> **旧版只警惕「低 PE 假便宜」。峰值盈利上的「正常 PE」同样危险，甚至更危险。**

**方向 A：周期顶部的假便宜（Forward PE < 10x）**
```
经典画像：
  Forward PE < 10x + PEG < 0.5     ← 看起来极便宜
  + 52 周涨幅 > 300%               ← 已在山顶
  + 毛利率创历史新高               ← 均值回归在路上
  + CAPEX/OCF > 60%                ← 利润被设备商抽走
  + Forward EPS 60-90 天内翻倍     ← 分析师线性外推暴利
  + 分析师一致看多

机制：Forward EPS 是分析师对未来 12 月的外推。顶部外推暴利 →
      FY22 MU Forward PE = 5x（看似极便宜）→ FY23 EPS 转负 → 股价腰斩
```

**★ 方向 B：峰值盈利上的「看似合理」PE（新增）**
```
若 PE 的分母是当期峰值盈利（run-rate / 峰值 forward），
则该 PE 必须与「周期顶部的正常 PE 区间」比较，而不是与全周期平均 PE 比较。

存储行业参考：MU 20 年平均 PE 约 10-15x；★周期顶部通常 5-8x（因分母是峰值利润）
→ 峰值盈利上的 31x，隐含的是「这不是周期股，是成长股」
→ 这个判断必须显式写出并标注为主观假设，不能藏在一个 PE 数字里

反例（CXMT）：分析正确写出「MU 周期顶部 PE 通常 5-8x」，
             但对比表仍用 31x 得出温和结论 —— 风险段与结论段互相矛盾。
```

**快速检查清单**
```
□ 52 周涨幅 > 200%？
□ 毛利率超 10 年均值 + 2σ？
□ CAPEX/OCF > 60%？
□ 历史上是否经历过 EPS 转负？
□ Forward EPS 60-90 天内暴涨 > 50%？
□ ★当期盈利是否为历史最高（即 PE 分母是峰值）？

≥2 个 Yes → 处于周期顶部区域：
  → PE / PEG 是噪音，不是信号
  → 切换到 PB 分位法 + EV/EBITDA + ★正常化 PE
```

**★ 正常化盈利（周期股主锚）**
```
normalized earnings ≈ 一轮完整周期的平均利润率 × 当前收入体量
              或    ≈ 同业 mid-cycle 盈利水平（MU/三星/海力士历史中周期）

三档并列，禁止只给一档：
  峰值盈利 PE = 市值 / 当期年化盈利     ← 顶部显得便宜
  中周期 PE   = 市值 / 正常化盈利       ← ★主锚
  底部盈利 PE = 市值 / 周期底部盈利     ← 下行风险
```

**周期位置 → 工具对照**
```
周期位置   | 该用                        | 不该用
──────────|────────────────────────────|──────────────
顶部       | PB 分位 · EV/EBITDA · 正常化PE | PE · PEG · DCF
中部       | EV/EBITDA · PB 分位          | PEG
底部       | PE（盈利已崩故 PE 高）· PB 分位 | PEG（分母过小）
```

**★ 重资产周期股必须给 P/B 或重置成本。** DRAM/面板 IDM 的估值下限历史上靠 P/B 撑住。
刚完成大额募资的公司（账上现金巨大）尤其不可漏 P/B。

### ★ 2.1.2 无历史数据标的（新上市/分拆/借壳）

> **§2.1.1 的检测清单全部依赖历史序列，对新上市标的整体失效。** 必须走替代路径。

```
失效项：52 周涨幅 · 自身 PE 历史分位 · 毛利率 10 年均值 · MA50/MA200 · Beta
        （步骤 4 黑箱观察整节基本不可用）

替代路径：
① 用同业历史分位替代自身分位（如 DRAM：MU / 三星 / 海力士的周期区间）
② 用行业周期位置替代公司周期位置（现货价 · 库存周期 · 行业资本开支周期）
③ 招股说明书 / 上市公告书是唯一的一手财务源（含业绩预告区间）
④ 首日上市标的：聚合数据源（akshare 等）可能尚未收录 → 属数据不可得，
   必须声明，不得用搜索数字伪装成结构化数据

⑤ ★禁止用当期数据伪造历史分位（"处于历史低位"在无历史时不成立）
```

### ★ 首日/近期上市标的的价格锚

**发行价 ≠ 当前可交易价格。** 首日上市标的常出现数倍差异，
用发行价下「贵/便宜」结论 = 回答一个已不存在的价格。

必须区分两个锚，并显式标注：

| 锚 | 含义 | 用途 |
|:--|:--|:--|
| 发行价锚 | 一级市场询价结果 | 判断「IPO 定价是否合理」 |
| ★二级市场锚 | 当前/开盘/最新成交价 | 判断「当前位置贵不贵」← 用户通常问这个 |

规则：
① 用户问「这个位置/现在/当前」→ 必须用二级市场锚
② 两个锚都可得 → 并列呈现，并指出方向差异
   （范例：「发行价 8.66 元 → 5.4x，为四家最低；
            开盘 49.5 元 → 31x，为四家最高。同一资产，两个相反结论」）
③ ★二级市场价不可得 → 声明「当前市价不可得」，
   仅可给出发行价锚的分析，并明确标注
   「以下结论基于发行价，非当前可交易价格」
   禁止在只有发行价的情况下给出「贵/便宜」的绝对判断
④ 首日涨跌幅是关键信号，必须尝试获取（开盘价 / 最新价 / 涨跌幅）

### ★ 新上市标的的 P/B 分母

**大额 IPO 募资会显著改变净资产。P/B 分母必须明确是募资前还是募资后。**

| 分母 | 何时用 | 陷阱 |
|:--|:--|:--|
| 募资前净资产 | 分析 IPO 定价合理性 | ★用于当前 P/B 会系统性高估 |
| 募资后净资产（=募资前 + 净募资额） | ★分析当前估值 | 须注明募资额与是否含超额配售 |

规则：
① 分析「当前位置」时必须用募资后净资产
② 输出中必须注明所用分母及募资额
③ 募资额占募资后净资产比例 > 20% 时，两个 P/B 必须并列呈现
④ 无法确认分母时标「P/B 分母未确认」，不得据此下「贵/便宜」结论

### 2.1.3 产品换代透支风险（Pull-Forward）

```
画像：全新架构刚量产 + Q1 营收 QoQ > 15% + 电话会提"initial deployment/building inventory"
→ Q1 高增速可能是客户囤货，非可持续消耗
→ Q2 环比下降则叙事切换：「超级周期」→「一次性脉冲」→ EPS 下修 + PE 压缩双杀

检查：□ 重大新产品量产？ □ QoQ > 15%？ □ 电话会囤货表述？ □ 下游存货上升？
≥2 Yes → 不可用 Q1 年化估全年 EPS；跟踪指标：Q2 环比是否不降
```
> 透支 ≠ 周期顶部：前者是时序错配，后者是结构问题。

**★ 政策/税收截止日导致的透支（中国市场常见）**
```
购置税/补贴/关税调整的生效日前后会产生需求前置 →
前一季被透支性拉高、后一季塌陷。这是全行业现象，不是个股问题。
出现"指引同比大幅下滑"时，先查是否有政策截止日，再谈竞争力恶化。
```

### 2.2 增长质量

```
- 营收 3-5 年 CAGR vs 最近增速（加速/减速/稳定）
- 利润增长 vs 营收增长 → 运营杠杆
- 利润率趋势（毛利/营业/净利，近 3 年）
- FCF/净利润 > 80% 优秀 / < 50% 关注
★ 量价拆分：营收变动 = 量 × 价。量价背离本身是结论
  （例：交付量 -33% 但营收 -18% → 隐含单价 +19% → 产品结构上移）
```

### 2.3 竞争优势（Moat）

| 维度 | 强 | 中 | 弱 |
|:----|:--|:--|:--|
| 网络效应 | 用户越多越有价值 | 有一定 | 无 |
| 转换成本 | 极高 | 有粘性 | 低 |
| 规模经济 | 显著成本优势 | 有但不明显 | 无 |
| 无形资产 | 品牌/专利/监管壁垒 | 一定壁垒 | 无 |
| 数据飞轮 | 用越多越强 | 有积累 | 无 |
| ★政策/供应链安全 | 唯一本土供应且被强制采购 | 部分替代 | 无 |

> 最后一行适用国产替代标的：即使技术落后一代，供应链安全溢价可能真实存在
> （但这是**主观假设**，必须显式标注并给出失效条件）。

### 2.4 财务健康

```
流动性  current ratio >1.5 ✅ / 1.0-1.5 ⚠️ / <1.0 🔴
杠杆    D/E <50% ✅ / 50-100% ⚠️ / >100% 🔴（行业差异大）
利息覆盖 EBIT/Interest >5x ✅ / 2-5x ⚠️ / <2x 🔴
现金    cash/debt >1.0 ✅ / 0.5-1.0 ⚠️ / <0.5 🔴
```

## 步骤 3：非常态性分析 — 催化剂与风险

### 3.1 财报催化剂
```
下次财报日（金十 MCP list_calendar）
一致预期 EPS/Revenue（websearch，★须标来源与时点；无免费权威源）
★公司自身 guidance（edgar.release 的 guidance 字段 / ashare 业绩预告）
  → 「实际 vs 公司指引」是免费且可追溯的，优于「实际 vs 卖方预期」
意外历史：过去 4 季 beat/miss
估值隐含预期：当前价隐含怎样的增长？
```

### 3.2 公司催化剂
```
新产品 · 重大客户/合同 · 管理层变动 · 资本配置（回购/派息/并购）
分拆/剥离/上市 · 监管裁决（FDA/反垄断/诉讼）
★A股特有：定增 · 解禁 · 股权激励 · 涨跌停制度对流动性的影响
```

```
★出口管制/实体清单（半导体尤其）：设备/零部件/维护服务的结构性风险
```

### 3.4 行业与宏观敏感性

## 步骤 4：黑箱观察 — 价格行为

> **★ 前置检查：标的是否有足够历史？** 新上市（< 3 个月）→ 本节大部分不可用，
> 直接声明「历史价格数据不足，技术面不可得」，**不要用几天数据做趋势判断**。

### 4.1 技术趋势
```
价格 > MA50 > MA200   多头排列
MA50 > 价格 > MA200   短期回调（中期仍好）
MA50 < MA200 < 价格   初步反转
价格 < MA50 < MA200   空头排列
成交量：放量突破 ✅ / 缩量上涨 ⚠️ / 放量下跌 🔴
缺口：gap up/down + 回补情况
```

### 4.2 相对表现
```
vs 大盘（SPX / 沪深300 / 恒指——★按市场选对基准）
vs 行业 ETF · vs 直接竞争对手
强弱是否持续或逆转
```

### 4.3 期权信号（可得则用，不可得则跳过）
```
IV 百分位 · IV vs HV · ATM straddle 隐含财报日波动 · Put/Call
⚠️ 无期权数据源时直接跳过，不要编造
```

### 4.4 内部人交易
```
insider 卖出 ≠ 利空（可能是 diversification）
insider 买入 > $1M → 通常看好
```

## 数据质量与溯源要求

```
① 财报数字走结构化源，输出中携带 audited / currency / caliber / period
② 实际值与前瞻值必须区分标注；前瞻值标「未验证」
③ 跨币种：换算须注明汇率与汇率日；本位币优先于折算值
④ 跨准则（CAS/US_GAAP/IFRS）不做直接比值运算
⑤ quote.verified 返回 confidence，低置信度必须显示
⑥ 派生值（PE/PS/利润率/同比）须能追溯到父节点实际值
⑦ 检索优先级：结构化 capability > RAG（29 篇归档，条件路由：定性优先/数字跳过）> websearch
```

## 禁止行为

```
❌ PE 裸用不标基准；把 run-rate 标注为 forward
❌ 周期股只给单点 PE（必须三档：峰值/中周期/底部）
❌ 峰值盈利上的 PE 与全周期平均 PE 直接比较
❌ 重资产周期股不给 PB
❌ 同业对比混用不同基准/期间/币种/准则/业务范围
❌ 非美元市场金额不核对币种（KRW/JPY「万亿」误读为美元）
❌ 用 websearch 取财报数字（有结构化源时）
❌ 结构化数据已取到却整列改用外网前瞻值
❌ 搜到卖方目标价/一致预期/官方指引却不纳入
❌ 风险段与结论段互相矛盾而不显式指出
❌ 新上市标的伪造历史分位 / 用几天数据做趋势判断
❌ 无数据填 0（无股息 ≠ 股息率 0%）
❌ 结构化源全失败后用搜索填补且不声明「未经结构化验证」
❌ 使用 LLM 记忆中的数字
❌ 不检索对立观点（必须搜 bull case + bear case，呈现至少一个有来源的反方）
```
