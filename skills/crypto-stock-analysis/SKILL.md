# Crypto Stock Analysis — 币股分析框架

> 币股不是传统科技股，也不是纯 crypto。它是两者的杂交品种——用美股的估值语言讲 crypto 的故事。
> 以 Strategy (MSTR) 及优先股 STRC 为原型案例，构建加密货币关联上市公司的系统性分析框架。

## 何时触发

- 分析 MSTR/COIN/MARA/RIOT/CLSK/IREN/BITF/HUT 等币股
- 用户问「MSTR 现在怎么样」「COIN 为什么不跟 BTC 涨」「矿企 PE 为什么这么低」
- 对比币股 vs 直接持有 BTC/ETH 的优劣
- 分析 Saylor 的融资操作（STRC/STRF/可转债）
- ⚠️ 需要宏观环境判断 → 同时加载 macro-analysis
- ⚠️ 需要 BTC 链上/市场数据 → 同时加载 crypto-analysis
- ⚠️ 需要传统估值对比 → 同时加载 us-stock-analysis

---

## 币股的定义与分类

指在公开市场交易的、价值与加密货币强关联的公司股票/优先股。主要类别：

| 类别 | 代表标的 | 核心关联资产 | 关键驱动因子 |
|:---|:---|:---|:---|
| BTC Treasury 公司 | Strategy (MSTR), Semler Scientific, Metaplanet | BTC 持仓 | BTC价格 / mNAV / 可转债市场 |
| 加密交易所 | Coinbase (COIN), Galaxy Digital | 交易量 / 加密市场整体 | 交易量 / USDC分成 / Base链 |
| 矿企 | MARA, Riot, CleanSpark, Core Scientific | BTC 价格 / 算力 | BTC价格 / 全网算力 / 电力成本 / 减半 |
| 加密银行/金融 | Anchorage | 加密生态资金流 | 托管规模 / 监管 |

---

## ⚠️ 步骤 0：标的解构（强制执行，不可跳过）

在对任何币股进行估值或预测之前，**必须先用 RAG + web 搜索完成以下解构**：

1. **标的身份**：这个 ticker 对应的金融工具到底是什么？（普通股？优先股？永续？有到期日？可转换？）
2. **现金流机制**：钱从哪来？支付给谁？是固定还是浮动？由谁决定何时调整？——**这是最易出错的一步**
3. **定价机制**：价格由市场供求决定，还是存在主动锚定机制（如发行人承诺维持 par）？
4. **控制权**：谁有权改变关键参数？这些权力在实际中是否被使用过？

完成后标注：
```
[标的解构] 身份: ... | 现金流: ... | 定价: ... | 控制权: ...
```

⚠️ **不完成这一步，禁止进入估值/预测环节。**

# MSTR 深度分析框架

## 核心公式：BTC 积累飞轮

```
BTC 积累飞轮 = STRC 融资 → BTC 购买 → 抬高 mNAV → 发行 MSTR 普通股去杠杆 → 更高的 BTC 持仓 → 更多 STRC 需求
```

## 关键指标与阈值

| 指标 | 含义 | 临界值 |
|:---|:---|:---|
| **mNAV** | MSTR 市值 / BTC 持仓市值 | >1x 飞轮正向运转；<1x 无法发股去杠杆 |
| **杠杆率** | 总负债 / 总资产 | 33%（参考值）。BTC -50% → 杠杆率 ~66% |
| **股息率** | STRC 浮动股息 | 从 9% 抬升至 11.5%（8个月内+250bps） |
| **ATM 增发量** | MSTR 普通股 ATM 周增发 | **=$0 是红灯**（mNAV 已紧到不能稀释） |
| **STRC VWAP** | STRC 月度成交均价 | **<$95 → 股息月 +50bps；$95-99 → 月 +25bps** |
| **BTC 持仓均价** | Strategy 持仓成本基础 | $75,577（参考），边际买入均价低于此 → 变薄缓冲 |

---

## STRC 三层死亡螺旋框架

任何依赖"融资→买币→抬估值→再融资"循环的 BTC treasury 公司，都可以套用此框架：

### 第一阶段：锚破裂

- 底层资产（BTC）深度下跌 → 杠杆率机械性上行 → 优先股信用质量恶化
- 价格跌破面值。已发生 3 次：2025.08 (~$92), 2025.11, 2026.02 (~$93)
- 每次修复的前提：BTC 在数周内反弹

### 第二阶段：融资成本陷阱

- 为维持面值锚，股息率被迫持续上调（STRC 机制：$95-99 → +25bps/月，<$95 → +50bps/月）
- 8 个月内 9% → 11.5%，平均月 +31bps
- $5B 规模下每 +100bps = 年增 $50M 现金支出；$20B 时 = $200M
- 熊市超过 6 个月 → 收益率可能推向 13-15%
- **股息暂停是关键信号：** (a) 需求企稳=看多；(b) 触及固收买家收益率天花板=看空

### 第三阶段：飞轮断裂

- mNAV < 1x → 发行普通股稀释股东 → Saylor 无法发股去杠杆
- 三难：继续高息发行 STRK（加杠杆）│ 下调股息（放弃稳定叙事）│ 卖 BTC（Saylor 说过永不）
- 前置条件：MSTR ATM 增发 $0，全部靠 STRC 融资 → 已部分触发
- 结论：最可能选 (b)——直接放弃 STRC 稳定叙事，压力全给持有人

## UST/Terra vs STRC 对比

| 维度 | UST | STRC |
|:---|:---|:---|
| 支撑资产 | 内生代币 LUNA | 真实 BTC + 自由裁量权 |
| 清算方式 | 算法强制铸销 | 可选择性下调股息 |
| 下限 | 理论归零 | 破产清算中的优先求偿权 |
| 崩溃条件 | 算法死亡螺旋 | 持续熊市（BTC<$50K 超 3 个月） |
| 风险性质 | 一夜崩盘 | 渐进式重定价（从准货币→困境收益产品） |

---

## 投资者视角：非对称风险结构

```
STRC 收益 = 好时候赚票息（11.5% 浮动）+ 坏时候承担集中单一 BTC 信用风险
本质 = 在 BTC 资产覆盖率上做空一个看跌期权
```

**多空分歧核心：**
- 看多派：市场上最安全的 11.5% 收益获取方式
- 看空派：被包装成货币市场产品的、定价错误的信用风险
- 关键差异：STRC 不会突然违约，而是慢慢重定价。渐进式滑坡才是真正风险

## MSTR 五维度分析检查清单

### 1. 融资飞轮健康度
- [ ] mNAV 是否 >1x？连续多久？
- [ ] 普通股 ATM 增发是否活跃？（=0 是红灯）
- [ ] 优先股/可转债融资占比趋势？
- [ ] 边际 BTC 买入价 vs 历史持仓成本（变厚还是变薄缓冲？）

### 2. 杠杆与偿付能力
- [ ] 当前杠杆率？BTC 再跌 30%/50% 后的杠杆率？
- [ ] 清算优先级：普通债 → 优先股 → 普通股，每层有多少缓冲？
- [ ] 是否有维持面值锚的机制（股息上调/回购承诺等）？

### 3. 股息/融资成本追踪
- [ ] 当前股息率？变化趋势（连续上调还是暂停？）
- [ ] 上调触发条件（如 VWAP 阈值）？
- [ ] 是否有正式上限？没有的话，极限场景下年化支出多少？
- [ ] 暂停是需求企稳还是触及天花板？

### 4. 反身性与脆弱性
- [ ] 飞轮依赖哪个关键假设？（如 mNAV>1x / BTC up-only）
- [ ] 该假设在什么条件下会失效？
- [ ] 失效后公司有哪些自由裁量权？（出售资产/下调股息/稀释股东）
- [ ] 修复需要多长时间？可否自我修复？

### 5. 机构持仓集中度
- [ ] 是否有少数大型持有人？（集中抛售 → 自我实现的崩盘）
- [ ] 日均成交量 vs 主要持有人持仓规模？
- [ ] 是否有"挤兑"风险？

## MSTR 飞轮状态判定

```
正常运转：
✅ mNAV > 1.0x          ← 能以溢价发普通股去杠杆
✅ BTC 趋势向上          ← 资产端升值
✅ STRC 守在 $100 面值   ← 融资通道畅通

降速信号：
⚠️ mNAV 接近 1.0x       ← 飞轮杠杆空间收窄
⚠️ 股息暂停上调

断裂条件（死亡螺旋）：
🔴 mNAV < 1.0x 连续 4 周
🔴 STRC VWAP < $95 连续 4 周
🔴 BTC 放量跌破 $55K
🔴 股息被迫上调至 13-15%
```

# 矿企分析

## 周期定位检查清单

```
□ 52 周涨幅 > 200%？→ 暂停 PE/PEG
□ 毛利率创历史新高？→ 周期顶部
□ CAPEX/OCF > 60%？→ 利润被矿机供应商拿走
□ 分析师一致上调 EPS？→ 追涨模式
□ 减半后 < 6 个月？→ 成本翻倍压力

如果 ≥ 2 个 Yes → 切换 PB 分位法 + EV/EBITDA
```

## 估值方法对照表

| 币股 | 该用什么 | 不该用什么 | 为什么 |
|:----|:--------|:---------|:------|
| **MSTR** | mNAV 分位法 | PE/PB/PEG | PE 毫无意义——伪装成软件公司的 BTC 买入机器 |
| **COIN** | P/S + 订阅收入占比 | PEG | 交易手续费强周期 |
| **矿企** | PB 周期分位法 + EV/EBITDA | PE/PEG | 周期股陷阱 |
| **矿企 CAPEX** | CAPEX/OCF 比 | — | >60% 预警 |

# COIN 分析要点

```
核心收入分解：
  交易手续费（强周期）→ 订阅和服务收入（USDC分成/Base排序器/staking）→ 占比从 90% 降到 ~50%
  
关键叙事转折：从「强周期赌场」到「弱周期基础设施」——估值应该给溢价

⚠️ 但 Coinbase 的 cost structure 与传统交易所完全不同：
  - 营业利润率受 BTC 价格波动影响极大
  - USDC 浮存金收益 = 储备 × (SOFR - distribution cost)
  - Base 链排序器收入是第三引擎
```

## 适用范围

本框架适用于**所有采用"融资→积累加密资产→抬升估值→再融资"循环的上市公司**，包括但不限于：
- BTC Treasury 公司（Strategy, Semler, Metaplanet）
- 未来可能涌现的 ETH Treasury 公司
- 任何以加密资产为主要资产负债表的上市公司

对于矿企和交易所，需叠加额外的算力/交易量维度，本框架的融资飞轮部分可复用。
