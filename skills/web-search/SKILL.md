# 网络搜索策略（Web Search）

## -1. 总闸门：先判断要不要碰外部信息

**这一步在四步法之前。** 以下场景**完全跳过搜索与 RAG**，直接用分析能力回答：

- 纯概念/框架问题（"PE 和 PB 的区别"、"什么是 MVRV"、"周期股怎么估值"）
- 纯逻辑推理（"如果降息 25bp，对 BTC 有什么影响"——要的是因果链不是新数据）
- 用户明确引用上文（"上次说的那个"、"你刚才提到的"）
- 用户提供了全部所需数据（"帮我算一下这两个数的同比"）

判断标准一句话：**这个问题的答案会随时间变化吗？** 不会 → 不搜。

## 0. 结构化优先：搜索前必须先问「有工具吗」

> **★ 最高优先级纪律。有结构化工具的数据，禁止走搜索。**

搜索得到的是**无溯源的文本数字**——它们进不了 Fact Registry，会被溯源闸门标为 `untraced`。
结构化工具返回的是**带 `currency / audited / period / caliber / accounting_standard / tier` 的 Fact**。

### 禁止走搜索的数据（必须走 capability）

| 数据 | 走这个 | 不要搜 |
|:-----|:-----|:-----|
| 美股/中概股财报 | `financial.edgar.facts`（年度·审计·XBRL） | ❌ |
| 美股/中概股季度业绩 | `financial.edgar.release`（6-K/8-K 新闻稿） | ❌ |
| **A股财报** | **`financial.ashare.report`** | ❌ |
| 美国宏观（利率/CPI/就业/M2/储备金） | `financial.fred` | ❌ |
| 行情/报价/估值倍数 | `financial.quote.verified` / `.query` | ❌ |
| **DeFi TVL / 稳定币 / 协议收入** | **`crypto.defi.*`** | ❌ |
| **资金费率 / 未平仓量 / 多空比** | **`crypto.derivatives.*`** | ❌ |
| **MVRV / 已实现市值 / 链上基本面** | **`crypto.onchain.metrics`** | ❌ |
| **恐惧贪婪指数** | **`crypto.sentiment.fng`** | ❌ |
| 知识库已有内容 | `financial.rag.search` | ❌ |

### 结构化数据锚定规则（与 BASE_AGENT_PROMPT 一致）

**结构化工具已返回数据时，输出必须锚在实际值上。**

```
✅ FY2025 营收 767.2 亿（EDGAR 20-F，已审计）；
   2026E 前瞻 ~2,200 亿（外网共识，⚠️ 未验证）
❌ 整列改用外网前瞻值，不提已取到的实际值
```

**反例（真实事故）**：某次分析已成功调用 `edgar.facts(MU)` 拿到 13 条审计过的 10-K fact，
但输出中 MU 全列使用 websearch 的前瞻数字 → 覆盖率 0%，且未能对邻列的币种错误形成参照。

## 1. 检索四步法

**确认要碰外部信息后，按顺序执行：**

| 步骤 | 动作 | 工具 | 什么时候跳过 |
|:--:|:-----|:-----|:-----|
| **0** | 结构化工具优先（见上表） | `financial.*` / `crypto.*` | 该问题无对应结构化源 |
| **1** | 知识库 | `financial.rag.search` | ① 不可用 / chunk=0 ② ★条件路由：纯数字问题跳过 ③ top-1 similarity < 0.5 → 代码层返回 no_relevant_match |
| **2** | 网络搜索 | 按资产类别选渠道（§2） | 步骤 1 有高质量命中且未过时 |
| **3** | 全文抓取 | `web.fetch` / `web.fetch_weixin` | 摘要已足够 |

**条件路由判据（步骤 1 跳过条件）：**

当问题同时满足以下三条 → 跳过 RAG，直接进入步骤 2：
- 明确标的（ticker / 公司名）
- 明确指标（营收/净利/EPS/PE/TVL/资金费率/CPI…）
- 明确期间（Q4 2025 / FY2025 / 最新）

示例：小鹏 Q4 2025 营收多少 · 茅台最新净利润 · BTC 资金费率 · 美国 CPI 最新数据 · 某协议 TVL

**相反**，问「为什么 / 怎么看 / 对比 / 趋势 / 框架 / 这个位置」→ RAG 仍然优先于 websearch。

**★ 相似度地板 0.5（代码层硬过滤，不是 prompt 建议）**：
- top-1 similarity < 0.5 → 整批结果视为 miss，返回 `{results: [], reason: "no_relevant_match", top_similarity: 0.47}`
- 低相关 chunk 不进 context，避免模型引用无关内容制造虚假深度
- agent 看到 no_relevant_match 后直接进入步骤 2，不在此反复搜索

**关于 `rag.status`**：已做会话级缓存（代码层），首次查询后缓存，后续复用。仅当 available=false 或 chunk_count=0 时才需重查。每问一次浪费一个 ReAct 轮次。

## 2. 按资产类别的搜索策略 ★

**不同资产的一手源、时效性、语言、陷阱完全不同。** 不要用一套策略打所有市场。

### 2.1 美股 / 中概股

```
一手源    SEC EDGAR（已有 capability，不用搜）
          公司 IR 官网 · 财报电话会 transcript
专业媒体  Bloomberg · Reuters · WSJ · Barron's · The Information
分析师    卖方研报摘要 · Seeking Alpha（质量参差）
语言      英文优先（一手文件与机构观点均为英文）
```

**搜索用途**：市场解读、一致预期、卖方目标价、管理层评论、行业竞争动态。
**不搜**：财报数字（走 EDGAR）、报价（走 quote）。

**⚠️ 陷阱**：一致预期（consensus）无免费权威源，搜到的数字务必标注来源与时点；
不同机构口径不同（GAAP vs non-GAAP、财年 vs 日历年）。

### 2.2 A股

```
一手源    巨潮资讯网（法定披露）· 上交所/深交所/北交所公告
          ★政策原文：国务院 · 发改委 · 央行 · 证监会 · 统计局 · 工信部
          交易所互动易 / 上证e互动（公司直接答投资者）
指定媒体  中国证券报 · 上海证券报 · 证券时报 · 证券日报（官方信披媒体，政策口径最权威）
专业媒体  财联社（盘中最快）· 华尔街见闻 · 第一财经 · 界面 · 21财经
语言      中文为主
```

**★ A股是政策驱动市场——政策原文是一手源，媒体解读是二手源。**
问"某政策对某板块的影响"时，**必须先找政策原文**，再看解读。禁止把某家媒体的解读当作政策本身。

**⚠️ A股 特有陷阱**：
- **小作文**：盘中未经证实的传闻会影响股价。来源为社交媒体/股吧/无署名 → 标 🔴 且注明"未经证实"
- **口径**：营业总收入 ≠ 营业收入；净利润 ≠ 归母净利润（差额为少数股东损益）
- **累计口径**：季报是累计值，"三季报净利"是前三季累计，不是 Q3 单季
- **新上市标的**：首日/近期上市公司，akshare 等聚合源可能尚未收录 → 属数据不可得（见 §6）

### 2.3 港股

```
一手源    HKEXnews 披露易（PDF 为主）· 公司 IR
专业媒体  智通财经 · 格隆汇 · 阿斯达克 · 信报 · 香港经济日报
语言      中文（繁/简）+ 英文（国际机构覆盖）
```

**★ 先判断标的类型再决定搜什么：**
```
美股+港股双重上市（中概股）→ 走 EDGAR，不搜财报
A股+H股双重上市            → 走 A股 通道
纯港股（腾讯/汇丰/友邦/长和）→ 只能搜；且港股主板仅强制半年披露，
                              不存在 Q1/Q3 单季报告
```

**⚠️ 陷阱**：准则双轨（A股 CAS vs H股 HKFRS，两套数字可合法不一致）；
币种混杂（HKD/CNY/USD）；纯港股无季度数据是**制度性缺失**，不是搜不到。

### 2.4 Crypto

```
一手源（最高）  项目官方博客 · 治理论坛（Discourse/Snapshot）· GitHub release
                官方 X · 交易所公告 · SEC 申报（ETF/上市公司持币）
专业媒体        The Block · CoinDesk · Blockworks · DL News · The Defiant
中文            PANews（已有 capability）· BlockBeats · Odaily · Foresight · 深潮
低质            Cointelegraph · 各类快讯农场（大量转载，不作独立来源）
语言            按目标源选：协议技术/机构动向→英文；国内叙事/交易所动态→中文
```

**★ 涉及协议升级、参数变更、融资、安全事件 → 先查一手源（官方博客/治理论坛/GitHub），媒体仅作补充。**
crypto 领域媒体误报率显著高于传统金融。

**时效分级比传统金融快一档**：L1 分钟级、L2 天级、L3 月级。

**⚠️ 陷阱**：转载率极高——五条"来源"常是同一篇通稿（见 §5 来源独立性）。

### 2.5 宏观

```
美国    ★FRED（已有 capability，21 系列，不用搜）
        一手：FOMC 声明/纪要 · BLS · BEA · Treasury · 美联储讲话原文
中国    ★一手：统计局 · 央行（社融/MLF/LPR）· 财政部 · 海关总署
        指定媒体：新华社 · 三大证券报
全球    IMF · World Bank · BIS · OECD
语言    对应发布机构语言
```

**★ 宏观最重要的是「发布时点」而非「数值」**——搜索必须标注上次发布日与下次发布日。
政策语言（"稳健""适度宽松""灵活适度"）的措辞变化本身是信号，**必须引用原文措辞，不得转述**。

**⚠️ 陷阱**：数据修正（GDP/非农常有大幅修正，注意是初值还是修正值）；
同比 vs 环比 vs 折年率口径混淆。

## 3. 搜索词构造

**不要把用户问题原样当搜索词。** 拆解 → 提取实体 → 按目标源选语言。

```
1. 提取核心实体（标的 / 指标 / 事件 / 时间锚）
2. ★按目标源选语言，不是无脑双语：
     要搜中文媒体/政策原文  → 中文
     要搜 SEC文件/机构研究  → 英文
     跨市场对比/国际事件     → 中英各一组
3. 加时间锚（当前是 2026 年，写"2026"或"最新"，不要写过去年份）
4. 最多 2 轮；每轮 query 必须与上一轮显著不同（换词/换角度/换源）
```

**示例**
```
"NVDA 最新财报毛利率"     → 英文为主：NVIDIA gross margin latest quarter earnings
"降准对银行股影响"         → 中文为主：央行 降准 2026 银行 净息差
                              + 先找央行公告原文
"某协议升级进展"           → 英文 + 一手：{protocol} upgrade 官方博客/GitHub release
"茅台三季报"               → 中文；且先走 financial.ashare.report
```

## 4. 时效性判断

| 等级 | 内容 | 过时标准 | 处理 |
|:--:|:-----|:-----|:-----|
| **L1 快变量** | 价格 · 利率 · 汇率 · 资金费率 | 传统 >1天 / crypto >1小时 | **不搜**——走 quote/fred/crypto.* |
| **L2 中变量** | 财报 · CPI · 非农 · 政策决议 · 项目动态 | > 1 个发布周期 | 搜最新发布 + 标注"上次发布 YYYY-MM-DD" |
| **L3 慢变量** | 产业结构 · 技术路线 · 赛道格局 | > 6 个月（crypto > 1 个月） | 搜最新研究 + 对比历史观点变化 |

**发布日期拿不到时 → 标「日期未知」，禁止推测。**（与"缺失不填默认值"纪律一致）

## 5. 交叉验证：先对口径，再谈差异

> **★ 顺序不能反。口径不同的两个数字，差异大是正常的，不是矛盾。**

```
① 先对口径：同一指标？同一时点？同一范围？同一币种？同一准则？
     不一致 → 这是两个不同的数，分别标注，不做取舍，不报警
② 口径一致后再看差异：同口径同时点、来源独立，数字仍显著不同
     → 这才是真矛盾 → 列双方数字 + 时间戳 + 去找一手源仲裁
```

**口径陷阱清单**
```
币种      ★KRW/JPY/CNY/HKD 的"万亿/兆"极易被误读为美元
          非美元市场的金额必须记录原始币种与单位
准则      CAS / US_GAAP / IFRS 的同名科目不可直接比较
期间      单季 vs 累计 vs 年化 vs TTM vs 前瞻
指标      营业总收入≠营业收入；净利润≠归母净利润；fees≠revenue
          run-rate PE ≠ forward PE（周期股两者可差数倍）
```

**⚠️ 量级异常断言（发现币种错误的最快方式）**
```
单季利润 > 该公司 TTM 全年        → 逻辑不可能，必为口径/币种错误
某公司市值 > 其所在市场总市值      → 同上
增速 > 1000% 且无并购/低基数解释   → flag
```

### 来源独立性（关键）

**五条搜索结果常常是同一篇通稿的五次转载。转载不是交叉验证，是回音室。**

```
判断：标题/核心数字/表述高度相似且时间接近 → 同一通稿 → 只算 1 个来源
处理：取 tier 最高者为代表，其余记为"另有 N 家转载"
规则：同一通稿组在任何"多源印证"逻辑中只算 1 个独立来源
```

## 6. 数据不可得是一等公民

**所有结构化源均失败 / 该数据在制度上不存在 → 显式声明，不用搜索填补。**

必须包含三要素：

```
① 为什么没有（制度/覆盖原因）
② 我们不做推算（纪律声明）
③ 有什么替代（可用的其他期间/口径/标的）
```

**示例**
```
腾讯 2025 Q3 营收 —— 数据不可得
  港股主板仅强制半年披露，不存在 Q3 单季报告；TCEHY 未在 SEC 注册，无 CIK。
  本系统不做推算。可提供：2025 H1 中期业绩。

长鑫科技（688825）估值 —— 结构化数据不可得
  今日首日上市，akshare 尚未收录；非 SEC 注册。
  以下数据来自外网搜索，⚠️ 未经结构化验证。
```

**★ 若最终仍使用搜索结果，必须在输出显著位置声明「未经结构化验证」**，
不能只依赖数字旁的 ⚠️ 角标。

## 7. 搜索结果可信度标注

**每个引用的外部信息必须标注：来源 + 发布日期 + 层级**

| 层级 | 来源类型 | 示例 |
|:--:|:-----|:-----|
| 🟢 一手 | 监管文件 · 交易所公告 · 政策原文 · 公司官方披露 · 项目官方博客/GitHub | SEC filing · 央行公告 · 巨潮公告 · HKEXnews · FOMC 声明 |
| 🟡 专业媒体 | 主流财经与行业垂直媒体 | Bloomberg · Reuters · 三大证券报 · 财联社 · The Block · PANews |
| 🔴 低 | 社交媒体 · 股吧/论坛 · 个人博客 · 无署名 · 内容农场 | X · 雪球评论 · 东财股吧 · Medium |

**规则**
```
🔴 来源不得作为数字的唯一依据；用于捕捉市场情绪时须明确标注"未经证实"
一手源与媒体解读冲突时 → 以一手源为准，并说明分歧
搜到 🟢 一手源后 → 不必再堆 🟡 来源凑数量
```

## 8. 搜到必须用

> **搜索结果里的关键信息，不得搜完不用。**

以下内容一旦出现在搜索结果中，**必须纳入输出**（哪怕与自己的判断相左）：

```
卖方目标价 / 目标 PE（须说明其基准年）
一致预期数字
官方指引（guidance）
监管/政策原文措辞
明确的对立观点
```

**反例（真实事故）**：分析中给出 CXMT 估值判断，
但搜索结果中已包含"野村目标价 116 元，基于 2028E EPS 5.8 元与 20 倍目标 PE"
——这是最直接的卖方锚，未被采用。

同类问题：搜索结果中已含正确的三星 PE（约 20x），
但输出采用了自行计算的错误值（6.4x，源于 KRW 被当作 USD）。

## 10. 失败处理矩阵

| 情况 | 处理 |
|:-----|:-----|
| rag 不可用 / 0 条 | 进入网络搜索 |
| PANews 0 条 | 换 `financial.websearch` + 英文关键词 |
| websearch 0 条 | 换关键词重试 1 次 → 仍 0 条 → 诚实告知 |
| 反爬 | 给出 URL + "该站有反爬保护，建议手动访问" |
| 付费墙 | 给出 URL + "需订阅，可从摘要获取部分信息"；标 `paywalled`，不猜内容 |
| 超时 >30s | 放弃该 URL，改用其他来源 |
| **所有结构化源失败** | **触发 §6 数据不可得声明** |
| 全部搜不到 | 诚实说"未找到"，不编造 |

## 11. 禁止行为

```
❌ 有结构化 capability 却走搜索（财报/宏观/行情/TVL/费率/MVRV/恐贪）
❌ 结构化数据已取到却整列改用外网前瞻值
❌ 跳过总闸门，对纯框架问题也去搜索
❌ 每个问题都重复调 rag.status（会话级缓存已做，代码层；首次调用后复用）
❌ 无脑中英双语（应按目标源选语言）
❌ 把同一通稿的多次转载当作多源印证
❌ 未对齐口径就报"数据矛盾"
❌ 非美元市场金额不记录原始币种（→ 币种误读）
❌ 搜到卖方目标价/一致预期/官方指引却不纳入
❌ 发布日期拿不到时推测一个
❌ 结构化源全失败后用搜索结果填补，且不声明"未经结构化验证"
❌ 加密问题不调 PANews
❌ 对所有 URL 逐一抓取（选最相关 2-3 个）
❌ 编造搜索结果
```
